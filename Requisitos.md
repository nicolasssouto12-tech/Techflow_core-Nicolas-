# REQUISITOS — TECHFLOW CORE

## 1. Objetivo

Criar um sistema em Python para cadastrar e controlar demandas e chamados técnicos.

## 2. Requisitos Funcionais (RF)

- **RF01:** Cadastrar novas demandas.
- **RF02:** Listar as demandas cadastradas.
- **RF03:** Buscar uma demanda pelo ID.
- **RF04:** Atualizar o status de uma demanda.
- **RF05:** Excluir uma demanda.
- **RF06:** Consultar CEP e cotação do dólar pela internet.

## 3. Requisitos Não Funcionais (RNF)

- **RNF01:** O sistema deve validar os dados digitados.
- **RNF02:** Não deve permitir IDs repetidos.
- **RNF03:** Deve ser fácil de usar.
- **RNF04:** Deve funcionar de forma rápida.
- **RNF05:** Não deve fechar inesperadamente quando ocorrer um erro.

## 4. Tecnologias

- Python 3.
- Visual Studio Code.
- API ViaCEP.
- AwesomeAPI.
